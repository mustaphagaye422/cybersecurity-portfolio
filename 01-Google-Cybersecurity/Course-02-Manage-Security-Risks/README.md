 Course Overview

This course focused on how organizations identify, assess, and reduce cybersecurity risks. It introduced the role of security policies, risk management frameworks, compliance, and security controls in protecting an organization's assets.

Key Concepts:

Risk

The possibility that a threat can exploit a vulnerability and negatively affect an asset.

 Asset

Anything valuable that an organization wants to protect.

 Vulnerability

A weakness that can be exploited.

 Threat

Anything capable of causing harm to an organization's systems, people, or data.
